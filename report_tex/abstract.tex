\begin{abstract}
Algorithmic trading systems are often built as disconnected modules in which forecasting, decision-making, and risk personalization operate independently. This project presents a unified personalized algorithmic trading platform for Indian equities that combines sequence-based prediction, reinforcement learning policy control, and trader behavior modeling inside a single deployment-ready pipeline. The system is designed for NSE-focused multi-symbol operation and uses a layered backend architecture in which market data processing, policy inference, and behavior personalization are integrated rather than appended.

The predictive component is based on an LSTM sequence model trained on 79,628 rows across 51 symbols, with sequence tensor shape \((78{,}098, 30, 5)\), 62,478 training sequences, and 15,620 validation sequences. The latest run reports 53,569 trainable parameters, best validation loss of 0.000205, and final validation loss of 0.000237 at epoch 30. This forecasting stage produces not only directional estimates but also prediction confidence, which is consumed by the downstream policy stage. The decision component is a PPO agent operating in a custom Gymnasium trading environment with a 5-action discrete space and 34-dimensional observation space. In the latest run, PPO completed 30,720 timesteps against a target of 30,000 in 277 seconds, with stable late-stage optimization statistics.

A central contribution of this implementation is behavior-aware policy conditioning. Questionnaire responses are transformed into a 15-dimensional normalized behavior vector that influences risk expression, capital aggressiveness, TP/SL preference, cooldown controls, and execution discipline. During inference, LSTM confidence and projected movement are injected into effective PPO behavior shaping before action selection. This creates a coupled inference loop where prediction certainty and policy control jointly determine final trade actions. Per-trade output is generated as absolute execution values, including capital allocation in INR, TP/SL ratio, stop-loss level, estimated quantity, and exact profit-target exit price for each stock request.

To evaluate behavioral imitation quality, this work uses AMA (Alignment Matching Accuracy), computed over capital, TP/SL, and profit-target conformity between generated plans and user-profile targets. The measured AMA for the latest run is 85.55\% over available watchlist predictions, indicating strong personalization fidelity while preserving symbol-level adaptivity. The runtime path also includes resilient fallback behavior to maintain inference continuity under live data-fetch disruptions. Overall, the proposed system demonstrates that combining LSTM confidence-guided PPO with profile-conditioned trade planning provides a practical path to personalized, risk-aware algorithmic trading rather than generic one-size-fits-all signal generation.
\end{abstract}
