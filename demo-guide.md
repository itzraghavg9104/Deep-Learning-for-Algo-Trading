# Demo Guide — AlgoTrade Platform

## Prerequisites (Before Demo)

```bash
# Terminal 1 — Backend
cd backend
source venv/bin/activate          # Unix
# .\venv\Scripts\activate         # Windows
uvicorn app.main:app --reload     # http://localhost:8000

# Terminal 2 — Frontend
cd frontend
npm run dev                       # http://localhost:3000
```

Verify backend is up:
- Open `http://localhost:8000/health` — should return `{"status": "healthy"}`
- Open `http://localhost:8000/docs` — Swagger UI should load

No Postgres/Redis needed — `demo_mode` is on by default.

## Demo Walkthrough (7 Steps, ~10 minutes)

### 1. Landing Page (`/`)

Opened by default at `http://localhost:3000`. Walk through:
- Hero section: "AI-Powered Trading Platform for Indian Markets"
- Three-layer architecture cards (Data Processing → Decision Engine → Trader Behavior)
- Call-to-action: "Get Started" links to register page

### 2. Register (`/auth/register`)

- Fill in **any email/password** (e.g. `demo@test.com` / `password123`)
- Password confirmation field must match
- Shows success message, then auto-logs in and redirects to `/dashboard`
- **Behind the scenes**: Demo mode auto-creates the user in memory (no DB needed)

### 3. Dashboard (`/dashboard`)

The main demo screen. Walk through:
- **Signals grid** — watchlist of NSE stocks with BUY/SELL/HOLD badges, confidence bars, price sparklines
- **Market clock** — shows "Market Open" or "Market Closed" based on NSE hours (9:15-15:30 IST, Mon-Fri)
- **Stats bar** — tracked symbols count, avg change, buy/sell distribution
- **Click a signal card** — opens a modal with:
  - Price chart (closing price + volume bars)
  - Signal gauge (confidence bar, green/red/yellow)
  - Technical indicators grid (RSI, MACD, SMA, EMA, Bollinger Bands, etc.)
- **Auto-refresh** — WebSocket connection pushes price updates every 30s
- **Sidebar** — navigation links + risk profile card (shows "Moderate" until risk assessment is done)

> **Tip**: Refresh signals by clicking the refresh icon. If models aren't loaded, the prediction service falls back to rule-based signals automatically.

### 4. Risk Assessment (`/profile/risk-assessment`)

- 6-question multiple choice questionnaire (1-4 scale)
- Questions cover: frequency of trading, reaction to losses, portfolio approach, turnover preference, news dependency, market knowledge
- Progress bar tracks completion
- On submit, shows results:
  - **Risk tolerance score** (0.0-1.0)
  - **Category**: Conservative / Moderate / Growth / Aggressive
  - **Recommendations**: max position size, suggested stop-loss, take-profit
- Score is now stored in the `DemoStore` — the sidebar will reflect it on next load

### 5. Backtest (`/backtest`)

- **Form fields**:
  - Symbol (e.g. `RELIANCE.NS`, `TCS.NS`, `INFY.NS`)
  - Start date / End date (requires 50+ trading days of data)
  - Initial capital (default INR 100,000)
  - Risk tolerance slider (matches profile if already assessed)
- On submit, runs PPO agent against historical data from `backend/data/raw/`
- **Results display**:
  - 8 metric cards: Total return, Sharpe ratio, Max drawdown, Win rate, Profit factor, Total trades, Final value
  - Equity curve chart (portfolio value over time via Recharts)
  - Recent trades table
- **Behind the scenes**: loads `ppo_trading_final.zip` model, runs `TradingEnv` simulation

> **Note**: Only stocks with CSV files in `backend/data/raw/` work. Preloaded: `RELIANCE.NS`, `TCS.NS`, `INFY.NS`, `HDFCBANK.NS`, `ICICIBANK.NS` etc. (20 Nifty 50 stocks).

### 6. Trade History (`/trades`)

- Lists all trades generated by backtests run during the session
- **Filter controls**: symbol text search, date range (from/to), export CSV
- **Stats**: filtered trades count, realized P&L, win rate
- **Table columns**: Date, Symbol, Action (BUY/SELL), Qty, Price, P&L
- Shows "No trades match your filters" if empty

> **Tip**: Run a backtest first (step 5) so this page has data to show.

### 7. Profile (`/profile`)

- **User info**: ID and email from registration
- **Risk profile**: tolerance score and category (updated after step 4)
- **Preferences form**:
  - Use sentiment toggle (off by default)
  - Preferred timeframe (intraday/swing/position/longterm)
  - Watchlist symbols (comma-separated, auto-saves)
- Save button persists to `DemoStore` for the session

## Key Talking Points for Demo

| Feature | What to Say |
|---------|-------------|
| **Three-layer architecture** | "Each layer is independent — data processing, decision engine, and behavior module. This makes it testable and extensible." |
| **Demo mode** | "Runs entirely in-memory with no infrastructure dependencies. Just Python and Node." |
| **PPO + LSTM** | "LSTM predicts price direction; PPO optimizes trade timing. The reward function uses Sharpe ratio, not raw returns." |
| **Fallback mechanism** | "If model files aren't found, the system gracefully falls back to rule-based signals. It never crashes." |
| **NSE/BSE support** | "Symbol normalization handles `.NS` and `.BO` suffixes automatically." |
| **WebSocket** | "Live price updates every 30 seconds during market hours. Auto-reconnects on disconnect." |
| **Kelly Criterion** | "Position sizing uses Kelly formula to balance risk and return based on the user's risk profile." |

## Troubleshooting Demo Issues

| Problem | Fix |
|---------|-----|
| Backend won't start | Check `MODEL_PATH` in `config.py` points to `./models`. Ensure `venv` is active and `pip install -r requirements.txt` ran. |
| Frontend shows blank page | Check `NEXT_PUBLIC_API_URL` in `.env.local` (default `http://localhost:8000/api/v1`). |
| Watchlist returns errors | Backend uses yfinance — needs internet. If yfinance rate-limits, wait 60s and retry. |
| Backtest returns "No data found" | Ensure `backend/data/raw/{SYMBOL}.csv` exists. Run `python training/download_data.py` to populate. |
| Signals show "rule-based" | LSTM/PPO models not found — `python training/train_lstm.py` then `python training/train_ppo.py` |
| Equity curve not rendering | Check Recharts dependency — should be in `package.json`. Build with `npm run build` if dev mode flaky. |
| Auth fails in demo mode | Demo mode auto-creates users for any credentials. Just re-register or refresh. |
| WebSocket not connecting | Check backend is on `:8000` and WebSocket path is `/api/v1/ws/prices`. |

## Quick Command Reference

```bash
# Start everything
cd backend && source venv/bin/activate && uvicorn app.main:app --reload
cd frontend && npm run dev

# Train models
cd backend && source venv/bin/activate
python training/download_data.py
python training/train_lstm.py
python training/train_ppo.py

# Build frontend
cd frontend && npm run lint && npm run build

# Docker (full stack)
docker-compose up --build
```
