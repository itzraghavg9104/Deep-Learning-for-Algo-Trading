# ABSTRACT

Algorithmic trading has evolved from rule-driven execution engines to data-intensive intelligent systems capable of adapting to dynamic market behavior. However, a major limitation in many existing approaches is the weak integration between market prediction, action optimization, and user-specific risk behavior. This project addresses that gap by proposing a **personalized AI-assisted algorithmic trading platform** that combines deep learning, reinforcement learning, and behavioral profiling in a unified architecture for Indian equity markets (NSE/BSE). The platform is built using Python 3.12, FastAPI, PyTorch, Stable-Baselines3 (PPO), Gymnasium, Next.js 16, React 19, PostgreSQL 15, and Docker Compose.

The proposed system adopts a three-layered backend design. **Layer 1 (Data Processing)** performs market data acquisition via yfinance for 52 NIFTY 50 stocks, computes 30+ technical indicators through pandas-ta, and constructs a 30-dimensional state vector for reinforcement learning. **Layer 2 (Decision Engine)** implements a custom Gymnasium trading environment with a 5-action discrete space (HOLD_BUY, HOLD_SELL, BUY, SELL, IDLE) and trains a PPO agent (Stable-Baselines3, MlpPolicy [256,256], 30,000 timesteps) using Sharpe ratio-based reward functions. **Layer 3 (Trader Behavior)** computes risk profiles from structured questionnaires, builds a 15-dimensional normalized behavior vector, and applies Kelly Criterion position sizing. Additionally, a supervised LSTM model (2-layer, hidden=64, seq_len=30, ~39K parameters) provides next-close price prediction, which is combined with the PPO action for the final trading signal.

The platform is operationalized through FastAPI REST endpoints and WebSocket (30-second polling interval for live prices), with a Next.js frontend featuring Zustand-based auth state management, Axios interceptors, Recharts charting, and React Hook Form validation. The implementation supports three runtime modes: Demo Mode (in-memory storage, no database), Firebase Mode (Firebase Auth + Firestore), and Full Production Mode (PostgreSQL + Redis + bcrypt JWT auth). Experimental results show the LSTM model achieves a validation loss of 0.000228 MSE, while the PPO agent yields an average return of 132.28% with a Sharpe ratio of 0.66 across 5 evaluation episodes. The system gracefully degrades to rule-based fallback when model artifacts are unavailable, ensuring continuous service.
